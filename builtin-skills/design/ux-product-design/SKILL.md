# UX Product Design

## Quando usar
- Desenhar/revisar fluxos de produto, onboarding, empty states

## Passos
1. Clarifique job-to-be-done e usuário alvo em 1–2 frases.
2. Mapeie happy path + erros + empty + loading.
3. Reduza passos até o valor; progressive disclosure.
4. Copy clara (veja `technical-writing` / product); CTAs óbvios.
5. Consistência com padrões da plataforma (web/iOS/Android).
6. Valide com protótipo rápido ou teste com 3–5 usuários quando o risco for alto.

## Armadilhas
- UI bonita que esconde o fluxo principal.
- Sem estado de erro/vazio.
- Jargão interno no UI.

## Verificação
- Flow completo narrável; estados cobertos; heurísticas Nielsen ok nas telas-chave.
