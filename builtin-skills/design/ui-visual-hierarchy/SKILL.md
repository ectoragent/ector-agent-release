# UI Visual Hierarchy

## Quando usar
- Telas confusas, hierarquia fraca, polish visual

## Passos
1. Uma ação primária por view; secundárias visualmente menores.
2. Escala tipográfica limitada; peso/size para hierarquia, não cor só.
3. Spacing consistente (grid/tokens).
4. Agrupe relacionados; whitespace como estrutura.
5. Contraste e foco para CTAs; evite competição de "botões gritantes".
6. Alinhe à brand existente do produto (não invente sistema paralelo).

## Armadilhas
- Muitos tamanhos de fonte/cores accent.
- Cards demais sem necessidade.
- Densidade irregular.

## Verificação
- Em 3s fica claro o que fazer; alinhamento e ritmo consistentes.
