# Web Development

Optional skills for client-side web development workflows — embedding agents, copilots, and AI-native UX patterns into user-facing web apps. Includes monorepo navigation (pnpm/turbo/nx workspaces).

These are distinct from Ector' own browser automation (Browserbase, Camofox), which operate *on* websites from outside. Web-development skills here help users build *into* their own websites.
